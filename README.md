# 🖥️ CSC Gerenciador Windows

Gerenciador completo de Desempenho, Aplicativos Instalados e Análise Profunda de Discos para Windows 10/11.

## 🚀 Funcionalidades
- **Desempenho & Boost**: Monitoramento em tempo real de CPU/RAM, limpeza de arquivos temporários (`%TEMP%`), liberação de memória RAM e troca de Plano de Energia (`Eco`, `Normal`, `Turbo`).
- **Gerenciador de Aplicativos**: Lista todos os aplicativos instalados no Registro do Windows (`Win32`, `Winget`, `Sistema`) com busca instantânea, filtro de pesados e desinstalação rápida (individual ou em lote).
- **Analisador de Discos & Espaço**: Lista todos os discos locais (`C:`, `D:`, `G:`, etc.), escaneia os maiores arquivos e pastas que mais ocupam espaço e permite excluí-los com 1 clique (com trava de segurança para pastas do sistema).
